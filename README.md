#### Modo de uso:

Para instalar los paquetes necesarios y ejecutar el programa, usar estos comandos:

```bash
# 1. Crear el entorno virtual (solo la primera vez)
python3 -m venv venv

# 2. Activar el entorno virtual (cada vez que se abra una terminal nueva)
source venv/bin/activate

# 3. Instalar las librerías necesarias (solo la primera vez)
python3 -m pip install -r requirements.txt

# 4. Ejecutar el programa
python3 poster.py
```
